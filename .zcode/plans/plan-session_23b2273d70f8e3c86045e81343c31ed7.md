Поддержка карт нормалей в спрайтах (движок RobustToolbox)

Формат: рядом с кадрами состояний .rsi кладутся файлы `<имя_состояния>_normal.png` (ваш пример: `icon_normal.png` для состояния `icon` в syndicate.rsi). Размер обязан совпадать с кадром/листом состояния. Если хотя бы у одного состояния есть нормаль — для остальных подставляется плоская нормаль (RGB 128,128,255), атлас нормалей строится с той же раскладкой, что и основной.

Влияние на свет (выбрано: градиент lightmap): во фреймворк-шейдере направление света берётся из градиента яркости lightmap в экранной точке; нормаль из карты масштабируется и модулирует lightSample. Плоская нормаль/отсутствие градиента = ровно прежняя картинка, unshaded-спрайты не затрагиваются.

Изменения в RobustToolbox:

1. Robust.Client/ResourceManagement/ResourceTypes/RSIResource.cs
   - LoadPreTextureFolder: после LoadImages для каждого состояния пробуем `<state>_normal.png`; собираем параллельный массив изображений (нет файла → плоская нормаль размера листа состояния; есть → валидация размера).
   - Второй RsiLoading.GenerateAtlas с теми же metadata/frameCounts → атлас нормалей с идентичной раскладкой.
   - LoadTexture: заливаем атлас нормалей через IClyde.LoadTextureFromImage с sRGB=false, регистрируем пару (см. п.3), атлас освобождаем.

2. Robust.Shared/Resources/RsiLoading.cs — без изменений формата meta.json (конвенция по именам файлов; полная совместимость со старыми RSI).

3. Clyde:
   - Clyde.Textures.cs: в LoadedTexture поле `ClydeHandle NormalTexture` (0 = нет); новый статический текстурный кэш `_stockTextureNormalFlat` (1px, 128,128,255) рядом с _stockTextureWhite; метод RegisterNormalTexture(Texture, Texture), доступный через IClydeInternal.
   - Clyde.Constants.cs: UniINormalTexture = 5, UniCount = 6, имя "normalMap".
   - Clyde.Rendering.cs, DrawCommandBatch: биндим Texture2 = нормаль главной текстуры батча либо плоскую заглушку; SetUniformTextureMaybe(normalMap, Texture2). Ничего в батчинге/командах не меняется — нормаль выводится из TextureId батча.
   - Диспоз нормали: так как пара живёт в рамках RSIResource, добавим сброс NormalTexture при удалении текстуры (в FlushTextureDispose/Dispose логику), чтобы не остался висячий handle.

4. Clyde/Shaders/base-default.frag: объявляем `uniform sampler2D normalMap;`; после `lightSample = LIGHT.xyz` вставляем блок (только при VtxModulate.x >= 0): сэмпл нормали по UV, если n.xy != 0 — 4 сэмпла lightmap вокруг Pos шагом SCREEN_PIXEL_SIZE, градиент яркости → направление света L, итог `lightSample *= 1 + strength * dot(n.xy, L) * интенсивность` (константы тюним по месту). Плоская нормаль → выход по ветке, ноль изменений.

5. CVar `display.normal_maps` (по умолчанию on): при выключении всегда биндится плоская заглушка.
